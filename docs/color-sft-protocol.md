# Color-reading LoRA pilot

Completed: smoke 41030910 and full 41030911. All 192 test responses and training logs downloaded and locally verified; full-map accuracy 16/48 to 22/48, crop 20/48 to 37/48. Saved adapter hashes verified. Results: analysis/hpc-color-sft-v1/color-sft-41030911/.

Purpose: test whether targeted supervised adaptation improves full-map target-color reading, with enlarged-crop examples supplying an easier presentation of the same training targets. This is an intervention hypothesis, not proof that language layers caused the observed failures.

Data: 11 source groups from the local ILAMB archive not used in the recent grid/color diagnostic series. The original historical benchmark may already include these maps: they are not newly downloaded or claimed globally untouched. One deterministic map per group; group-disjoint split fixed before model inference: six train, two development, three test. Raw-image hashes also cannot cross splits. Exclude all ten recent diagnostic source groups. New point samples use only stable visibly colored image patches and avoid grid boundaries; no model-output selection. These are image-RGB targets, not geographic/land/NetCDF reference claims.

Sampling: fixed seed 20261108, minimum point separation 24 pixels. Train 24 points per source, dev eight, test 16. Each point has a full map and fixed 5x nearest-neighbor crop, sharing six swatches and answer. Swatch positions randomized independently of model output, balanced as closely as possible per map. Source center RGB and paired choice panels verified exactly. Total 288 training images (144 points), 32 development images (16 points), 96 test images (48 points). Exact center RGB is one choice; five distinct alternatives come from the same map palette. The crop/full pairing is supervised data augmentation; no consistency loss or feature alignment is claimed.

Primary endpoint: base versus adapted full-map accuracy on 48 test points from THREE source groups. Crop accuracy secondary on the same 48 points, not 48 additional independent sources. Invalid answers count incorrect; report validity and paired changes and per-source counts. No significance/permutation test. Only a small one-seed pilot; no broad generalization or novelty claim.

Model: Qwen2.5-VL-7B-Instruct revision cc594898137f460bfe9f0759e9844b3ce807cfb5. Freeze all original and visual-encoder weights. Train language self-attention q_proj/v_proj LoRA only, rank 8, alpha 16, dropout 0. Assert that no visual/base parameter is trainable. Unquantized BF16, SDPA, nonreentrant gradient checkpointing. Assistant digit plus closing-token labels only, after image-token expansion; verify user prefix and reject truncation above 2048 tokens.

One fixed epoch, LR 1e-4, AdamW weight decay zero, batch one, accumulation four, max gradient norm one. 288 microsteps / 72 optimizer updates. Final epoch checkpoint only; no test/dev checkpoint selection or hyperparameter sweep. Log dev token loss before/after descriptively. Paired baseline uses disabled adapter; adapted evaluation reloads the saved adapter. Both use identical images, prompt from the plain-patch diagnostic, processor min_pixels=3136 / max_pixels=1003520 and greedy generation with 16 new tokens. The improved-resolution intervention is deliberately held out of this comparison to isolate adapter training.

Gate: two TRAIN images, one update, two DEV evaluations and loss checks only; no test examples in smoke. Verify finite gradients, LoRA norm change, memory, and save/reload. Full job requires successful smoke metadata matching dataset, code and hyperparameters, and starts again from the unchanged base (not smoke weights). A failed smoke blocks full evaluation. Save training scope, complete raw base/adapted responses, training logs, metadata and adapter hashes.

Artifacts: scripts/prepare_color_sft.py; scripts/color_sft_pilot.py; slurm/run_color_sft.sbatch; tests/test_color_sft.py; experiments/color-sft-v1/ includes source PNGs, manifest, source groups and frozen images. Freeze code/data in a separate HPC submission snapshot. analysis/hpc-color-sft-v1/ records submissions and downloaded results. No earlier raw data or experiment is overwritten.
